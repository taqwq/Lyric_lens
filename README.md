# Lyric Lens for Genius

Genius の歌詞ページで、英語の各行のすぐ下に日本語訳を入れるユーザースクリプトです。

1行ずつ機械的に訳すのではなく、曲全体を読んだうえで訳します。スラングやダブルミーニングのように、訳だけでは伝わりにくい箇所にだけ短い注（※）が付きます。見た目はなるべく Genius に馴染むようにしてあります。

翻訳には Gemini API を使います。無料の API キーがあれば動きます。

## 使い方

歌詞の上（Genius の「〇〇 Lyrics」の下）に「日本語で読む」ボタンが出ます。押すまでは Gemini に何も送りません。

押すと、まず曲の前書き（誰が誰に歌っているか、どんな曲か）が出て、そのあと訳が上の行から順に入っていきます。Yeah や Woah のような声だけの行は訳さず、薄く ♪ を置いています。

- **※** を押すと、その行の下に注が開きます。歌詞の該当箇所も黄色くなるので、どの言葉の話かすぐわかります。関係する Genius の注釈があれば、英語のまま開いて読めます。
- **途中で途切れた**ときは、混雑や長い曲の区切りなど、もう一度頼めば進むものなら、そのまま残りを訳し続けます。止まるのは、自分で止めたとき、今日の無料枠を使い切ったとき、APIキーが使えないとき、接続が切れたとき、続けても1行も進まなかったときだけです。そのときは止まった行に線が引かれて理由が出て、「続きを訳す」で残りだけ訳します。
- **一度訳した曲**は保存されるので、次からは開いた時点で訳が入っています。あとから Genius 側で歌詞が直された場合は、新しい行だけ訳せます。
- **訳を隠す**で原文だけに戻せます（曲ごとに覚えています）。
- 歌詞がもともと日本語の曲では何もしません。

設定（API キー、この曲の訳し直し・削除、直近のエラー、保存データの書き出し／読み込み）は、ボタン横の「設定」か、スクリプトマネージャーのメニュー「Lyric Lensの設定」から開けます。

## インストール

1. ユーザースクリプトマネージャーを入れます。PC なら Tampermonkey か Violentmonkey、Android なら Firefox + Tampermonkey、iPhone なら Safari 拡張の「Userscripts」。
2. [lyric-lens.user.js](https://github.com/taqwq/Lyric_lens/raw/master/dist/lyric-lens.user.js) を開いてインストールします。
3. Genius の歌詞ページで「日本語で読む」を押すと、API キーの入力欄が出ます。[Google AI Studio](https://aistudio.google.com/app/apikey) で無料のキーを作って貼り付け、「保存してこの曲を訳す」を押せば始まります。

## 無料枠のこと

Gemini の無料枠は、モデルごとに1日20回くらいが目安です（2026年10月に試した感じ）。1曲はふつう1回で済みます。

混んでいたり上限に達したりしたモデルは、自動で別のモデルに切り替えます。新しい Flash 系（Gemini 4 Hydrogen など）を先に試し、だめなら Flash-Lite、最後に Gemma の順です。Flash が遅いときは、しばらく Flash-Lite を先に使います。

その日の上限に達したモデルは、枠がリセットされるまで使いません。リセットは太平洋時間の0時で、日本時間だと夏は16時、冬は17時です。全部のモデルが上限なら何も送らずに、次に訳せる時刻を表示します。

翻訳は全タブ合わせて1曲ずつです。同じ曲を別のタブで開いても、そちらは保存された訳を表示するだけです。

## 送るデータ

「日本語で読む」を押したときに、曲名・アーティスト・アルバム・歌詞・Genius の曲解説と注釈を Gemini API に送ります。送り先はここだけです。

Genius の注釈は、ページを開いたときに Genius 自身の API から読み込んでいます（キーが保存済みか、訳済みの曲のとき）。

API キーはユーザースクリプトの保存領域にだけ置いています。Gemini の無料枠では、送った内容が Google のサービス改善に使われることがあるので、その点は承知のうえで使ってください。

## 開発

```bash
npm install
npm run check   # 型チェック → テスト → ビルド（dist/lyric-lens.user.js）
```

- `node scripts/build.mjs --dev` のあと `node scripts/serve.mjs` で http://localhost:5178/ に Genius 風のテストページが立ちます。API は呼ばず、疑似モデル（`dev/mock-llm.js`）が返事をします。`localStorage['ll-mock-mode']` に `cut` / `quota` / `busy-first` / `slow` / `garbage` を入れると、失敗したときの動きを確かめられます。
- `node scripts/snapshot.mjs <GeniusのURL> [--mobile]` で実際のページを `dev/real/` に保存します。Genius のスクリプトを外して、開発版と疑似モデルを差し込んだものです。
- 本物のモデルで訳を確かめるときは、`.env.local` に `GEMINI_API_KEY=...` を書いて `npm run live -- <GeniusのURL> [--model …]`。訳と注の一覧が `tmp/report-*.md` に出ます（無料枠を1回使います）。

```
src/
  core/      曲の行の整理（繰り返し・声だけの行）、プロンプト、返ってきた訳の読み取り
  llm/       Gemini の呼び出し、モデルの選び方と切り替え、エラーの分類
  platform/  GM_xmlhttpRequest とストレージ
  genius/    歌詞の読み取りと差し込み位置、Genius の注釈
  store/     設定、曲ごとの保存、タブ間のロック
  ui/        画面の状態（state.ts）、見出し行、訳の行、注、設定シート
  app.ts     全体のつなぎ
```

設計の考え方は [docs/DESIGN.md](docs/DESIGN.md) にまとめています。
