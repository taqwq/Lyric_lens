# Lyric Lens for Genius (v3)

Genius の歌詞ページで、**曲全体の文脈を踏まえた自然な日本語訳**を各行の真下に出し、**本当に必要な行にだけ注釈**を付けるユーザースクリプトです。無料の Gemini API キーだけで動きます。

## できること

- **Genius を離れずに読める**：右下のボタンを押すだけ。Genius の公式注釈ともそのまま併読できます。
- **原文の真下に訳**：行ごとに照らし合わせられる、口調・温度感を残した訳。訳は届いた行から順に表示されます。
- **曲全体を踏まえて訳す**：1曲を1回のリクエストでまるごと読ませ、語り手・相手・展開をつかんでから訳します。繰り返しのサビは自動で同じ訳に揃います。
- **必要な行にだけ注釈**：スラング／言葉遊び／背景／慣用句／二通りの読み。「注」ボタンを押したときだけ開きます。推測を含む注釈には「推測」と表示。
- **Genius のコミュニティ注釈を根拠に使う**：翻訳時に Genius の注釈（人が書いた解説）を参考情報としてモデルに渡すので、スラングや固有名詞の読み違いが減ります。
- **止まっても失わない／一度読んだ曲はすぐ出る**：届いた行はその場で保存。途中で切れても「続きを訳す」で残りだけを訳します。訳は行ごとに保存されるので、Genius 側で歌詞が少し直されても、変わった行だけ訳し直せば済みます。
- **「この曲について」カード**：モデルが訳す前につかんだ曲の構図（何をしている曲か、誰が誰に語っているか）を歌詞の上に表示します。

## 入れ方

1. ブラウザにユーザースクリプトマネージャーを入れる
   - PC：Tampermonkey（推奨）または Violentmonkey
   - Android：Firefox ＋ Tampermonkey
   - iPhone / iPad：Safari 拡張「Userscripts」
2. `dist/lyric-lens.user.js` をマネージャーにインストールする
   - 旧版（v2.x）と同じ名前空間なので、上書き更新になります。旧版の Gemini API キーは自動で引き継ぎます。
3. Genius の歌詞ページを開き、右下の「歌詞を訳す」を押す
   - 初回は設定画面が開くので、Gemini API キーを貼って「保存」。そのまま翻訳が始まります。
   - キーは [Google AI Studio](https://aistudio.google.com/app/apikey) で無料で作れます。

## 使い方

| 右下のボタン | 状態 | 押すと |
|---|---|---|
| 歌詞を訳す | 未翻訳 | 翻訳を始める |
| 曲を読んでいます / 訳しています 34/67 | 翻訳中 | 進み具合と使っているモデルを表示（中止もここから） |
| 続きを訳す · 残りN行 | 途中で止まった／歌詞が更新された | 残りの行だけ訳す |
| もう一度試す | エラー | 原因と対処を日本語で表示 |
| 訳を隠す／訳を表示 | 完了 | 訳の表示を切り替える（Alt+T） |

「⋯」メニュー：訳の表示切り替え、「この曲について」の表示切り替え、この曲を訳し直す、保存した訳を削除、設定。

## 無料枠について（重要）

- Gemini の無料枠は **1モデルあたり1日20回前後**（2026年10月時点の実測）。1曲は通常1回で済みます。
- 混雑（503）や上限（429）のときは、**自動で別のモデルへ切り替えます**。上限に達したモデルはリセット時刻（太平洋時間0時＝日本時間16時/17時）まで使いません。
- それでも足りないときは、設定の「予備の API」に無料枠のある Groq / Cerebras / OpenRouter / Mistral や、ローカルの Ollama を追加できます。上から順に使われます。
- 「曲を開いたら自動で訳す」をオンにすると、開いた曲すべてで無料枠を使うので注意。

## 送信されるデータ

翻訳するときに、曲名・アーティスト・アルバム・歌詞・Genius の曲解説と注釈を、設定した API（既定は Google Gemini）へ送ります。API キーはユーザースクリプトのストレージにだけ保存され、ほかには送られません。エラー詳細のコピーではキーを伏せ字にします。Gemini の無料枠では、入力が Google のサービス改善に使われる場合があります。

## 開発

```bash
npm install
npm run build        # dist/lyric-lens.user.js
npm test             # vitest（単体テスト）
npm run typecheck
npm run check        # typecheck + test + build
```

- **開発用ページ**：`node scripts/build.mjs --dev` のあと `node scripts/serve.mjs` → http://localhost:5178/ 。Genius を模したページと、API を呼ばない疑似モデル（`dev/mock-llm.js`）で動きます。`localStorage['ll-mock-mode']` を `busy-first` / `cut` / `quota` / `slow` / `garbage` にすると失敗ケースを再現できます。
- **実ページのコピー**：`node scripts/snapshot.mjs <Genius の URL> [--mobile]` で `dev/real/` に保存（Genius のスクリプトは除去、開発版と疑似モデルを注入）。
- **実モデルでの品質確認**：`.env.local` に `GEMINI_API_KEY=...` を書いて `npm run live -- <Genius の URL> [--model gemini-3.6-flash] [--thinking low|medium|high]`。訳と注釈の対照表が `tmp/report-*.md` に出ます（無料枠を1回使います）。

### 構成

```
src/
  core/      曲モデル（行の正規化・重複除去）、プロンプト、ストリーミング行プロトコル、翻訳パイプライン
  llm/       Gemini / OpenAI 互換プロバイダー、SSE、混雑・上限を覚えるフォールバック
  platform/  GM_xmlhttpRequest のストリーミング、GM ストレージ
  genius/    歌詞の抽出と訳の差し込み位置、Genius 注釈 API
  store/     設定、曲ごとの保存（行テキスト単位）
  ui/        行内の訳と注釈、要約カード、操作ボタン、設定画面
  app.ts     ページ・翻訳・保存・UI をつなぐ制御
```

モデルの出力は JSON ではなく、1行1レコードのテキスト（`L12: 訳` / `N12: slang | 語句 | 説明`）です。届いた行から表示でき、途中で切れても切れる前の行は全部使え、構造化出力のないモデルでも同じように動きます。
