# Lyric Lens for Genius (v3)

**聴きながら、わかる。** Genius の歌詞ページで、英語の各行の真下に、曲全体を踏まえた自然な日本語訳を入れるユーザースクリプトです。見た目は Genius のデザイン（下線付きのリンク、黄色のマーカー）にそろえてあり、読み違えやすい語句にだけ「※」の注が付きます。無料の Gemini API キーだけで動きます。

設計の考え方と全仕様は [docs/DESIGN.md](docs/DESIGN.md) に、見た目の設計の経緯（独立した複数の設計案を、いくつもの観点で審査して統合したもの）は [docs/design-plan-v4.md](docs/design-plan-v4.md) にあります。

## 読み方

- **歌詞のいちばん上**（Genius の「〇〇 Lyrics」のすぐ下）に「日本語で読む」が出ます。押したときだけ翻訳が始まり、無料枠を1回使います。ページを開いただけ、スクロールしただけでは何も送りません。訳している間は、その行の下の線が進み具合を示します。
- **訳が入る場所**：押すと英語の各行の下に余白が開き、届いた行から訳が入っていきます。いま訳している行には、細い縦線がゆっくり明滅します。声だけの行（Yeah, yeah など）は訳さず、代わりに薄い「♪」を置きます。
- **前書き**：訳し始める前に、曲の構図（誰から誰への歌かを示す一文と、曲の要点）が、いちばん上の行の下に出ます。訳を待つ間に読めます。
- **※（注）**：日本語の行末の「※」を押すと、その行の下に注が開きます。歌詞の中の該当語句・※・注の見出しが同時に黄色くなり、どの言葉の話かが一目でわかります。関連する Genius の注釈（英語）も、注の中で読めます。繰り返しの行は淡い色になり、※から同じ注を開けます。
- **途中で止まったら**：訳した最後の行の下に線が引かれ、止まった理由（混雑、回数制限、今日の無料枠、接続など）と「続きを訳す」が出ます。線より下は素の Genius のままです。「続きを訳す」を押すと、残りの行だけを訳します。自動では続けません。
- **一度読んだ曲**は、開いた時点でもう訳が入っています。Genius 側で歌詞が直されたら、変わった行だけを訳し直せます。
- **訳を隠す**：曲を聴きながら原文だけで読みたいとき。曲ごとに覚えておきます。
- **設定**：Gemini の API キー、この曲の訳し直しと削除、直近のエラー、保存データの書き出しと読み込み（別の端末に移せます）。

## 入れ方

1. ユーザースクリプトマネージャーを入れる（PC：Tampermonkey／Violentmonkey、Android：Firefox と Tampermonkey、iPhone：Safari 拡張「Userscripts」）
2. `dist/lyric-lens.user.js` をインストールする（v2 からは上書きで更新でき、Gemini キーもそのまま引き継ぎます）
3. Genius の歌詞ページで「日本語で読む」を押す → [Google AI Studio](https://aistudio.google.com/app/apikey) で無料の API キーを作り、コピーして貼り付ける →「保存してこの曲を訳す」を押す

## 無料枠について

- Gemini の無料枠は **1モデルにつき1日20回ほど**（2026年10月時点の実測）。1曲は1回で済みます。混雑（503）や上限のときは、自動で別の Gemini モデル（Flash → Flash-Lite → Gemma の順）に切り替えます。
- 上限に達したモデルは、リセット（日本時間の16:00、冬は17:00）まで使いません。すべてのモデルが上限のときは何も送らず、「今日の無料枠を使い切りました」と「16:00から、また訳せます」を表示します。
- 同じ曲を2つのタブで開いても、リクエストは1本だけです（別のタブは保存された訳を追いかけて表示します）。

## 送信されるデータ

翻訳するときに、曲名・アーティスト・アルバム・歌詞・Genius の曲解説と注釈を、Gemini API へ送ります（送り先はそれだけです）。API キーはユーザースクリプトの保存領域にだけ保存されます。Gemini の無料枠では、入力が Google のサービス改善に使われることがあります。

## 開発

```bash
npm install
npm run check        # 型チェック + 単体テスト + ビルド → dist/lyric-lens.user.js
```

- **開発用ページ**：`node scripts/build.mjs --dev` → `node scripts/serve.mjs` → http://localhost:5178/ を開く。Genius を模したページと、API を呼ばない疑似モデル（`dev/mock-llm.js`）で動きます。`localStorage['ll-mock-mode']` を `cut` / `quota` / `busy-first` / `slow` / `garbage` にすると失敗ケースを再現できます。
- **実ページのコピー**：`node scripts/snapshot.mjs <Genius の URL> [--mobile]` → `dev/real/`（Genius のスクリプトを除き、開発版と疑似モデルを注入）。
- **実モデルでの品質確認**：`.env.local` に `GEMINI_API_KEY=...` → `npm run live -- <Genius の URL> [--model …]`。訳と注の対照表が `tmp/report-*.md` に出ます（無料枠を1回使います）。

### 構成

```
src/
  core/      曲モデル（行の正規化・繰り返しの検出）、プロンプト、1行ずつの JSON 出力の解析、1タップ1リクエストの翻訳
  llm/       Gemini のみ。ストリーミング、モデルの階層ごとの候補・状態順の選択、混雑・上限を覚えるフォールバック、エラーの分類、送る前の空き確認
  platform/  GM_xmlhttpRequest のストリーミング、GM ストレージ
  genius/    歌詞の抽出と差し込み位置、注の語句の位置特定、Genius 注釈 API
  store/     設定、曲ごとの保存（行テキスト単位）、タブをまたぐ実行ロック
  ui/        状態の決定（state.ts：S1〜S8f を純粋関数で）、頭の1行、訳の行、注、設定シート（Shadow DOM）
  app.ts     ページ・保存・ロックから状態の入力を集め、操作を結びつける制御
```
