# Lyric Lens for Genius

Genius の歌詞ページで、英語の各行の下に日本語訳を表示するユーザースクリプトです。

曲全体の文脈を踏まえて訳します。スラングや二重の意味など、訳だけでは伝わりにくい箇所には短い注（※）を付けます。表示は Genius のデザインに合わせています。

翻訳には Gemini API を使います。無料の API キーで利用できます。Anthropic の API キーを設定した場合は、Claude Opus 5.5 を優先して使います。

## 使い方

歌詞の上（Genius の「〇〇 Lyrics」の下）に「日本語に翻訳」ボタンが表示されます。ボタンを押すまで、AI には何も送信しません。

ボタンを押すと、最初に曲の概要（誰が誰に向けて歌っているか、どのような曲か）が表示され、続いて上の行から順に訳が表示されます。Yeah や Woah など声だけの行は翻訳せず、♪ を表示します。

- **※** を押すと、その行の下に注が開き、歌詞の該当箇所が黄色で示されます。関連する Genius の注釈がある場合は、英語の原文を開いて読めます。
- **翻訳が途中で中断した**場合、混雑や長い曲の区切りなど再試行で進められるものは、自動で続きを翻訳します。次の場合は停止します：手動で停止したとき、本日の無料枠を使い切ったとき、APIキーが無効なとき、接続が切れたとき、再試行しても1行も進まなかったとき。停止した行に線と理由が表示され、「続きを翻訳」で残りの行だけを翻訳できます。
- **翻訳済みの曲**は保存され、次回からはページを開いた時点で訳が表示されます。Genius 側で歌詞が更新された場合は、追加された行だけを翻訳できます。
- **訳を隠す**で原文のみの表示に戻せます（曲ごとに記憶します）。
- 歌詞が日本語の曲では動作しません。

設定（API キー、この曲の再翻訳・削除、直近のエラー、保存データのエクスポート／インポート）は、ボタンの横の「設定」、またはスクリプトマネージャーのメニュー「Lyric Lensの設定」から開けます。

## インストール

1. ユーザースクリプトマネージャーをインストールします。PC では Tampermonkey または Violentmonkey、Android では Firefox と Tampermonkey、iPhone では Safari 拡張機能の「Userscripts」を使います。
2. [lyric-lens.user.js](https://github.com/taqwq/Lyric_lens/raw/master/dist/lyric-lens.user.js) を開いてインストールします。
3. Genius の歌詞ページで「日本語に翻訳」を押すと、API キーの入力欄が表示されます。[Google AI Studio](https://aistudio.google.com/app/apikey) で無料のキーを作成して貼り付け、「保存してこの曲を翻訳」を押すと翻訳が始まります。

## 無料枠について

Gemini の無料枠は、モデルごとに1日20回程度です（2026年10月時点の実測）。1曲の翻訳には通常1回を使います。

混雑しているモデルや上限に達したモデルは、自動で別のモデルに切り替えます。新しい Flash 系（Gemini 4 Hydrogen など）を最初に試し、利用できない場合は Flash-Lite、最後に Gemma の順に切り替えます。Flash の応答が遅いときは、しばらくの間 Flash-Lite を優先します。

本日の上限に達したモデルは、無料枠がリセットされるまで使用しません。リセットは太平洋時間の0時（日本時間で夏は16時、冬は17時）です。すべてのモデルが上限に達している場合は何も送信せず、次に翻訳できる時刻を表示します。

翻訳は、すべてのタブを合わせて同時に1曲ずつ行います。翻訳中の曲を別のタブで開いた場合、そのタブでは保存済みの訳を表示します。

## 送信するデータ

「日本語に翻訳」を押すと、曲名、アーティスト名、アルバム名、歌詞、Genius の曲解説と注釈を、翻訳に使う AI の API（Gemini API、または Anthropic の API）に送信します。それ以外には送信しません。

Genius の注釈は、ページを開いたときに Genius の API から読み込みます（キーを保存済みの場合、または翻訳済みの曲の場合）。

API キーは、ユーザースクリプトマネージャーの保存領域にのみ保存します。Gemini の無料枠では、送信した内容が Google のサービス改善に使用される場合があります。

## 開発

```bash
npm install
npm run check   # 型チェック → テスト → ビルド（dist/lyric-lens.user.js）
```

- `node scripts/build.mjs --dev` の後に `node scripts/serve.mjs` を実行すると、http://localhost:5178/ に Genius を模したテストページが開きます。API は呼び出さず、疑似モデル（`dev/mock-llm.js`）が応答します。`localStorage['ll-mock-mode']` に `cut` / `quota` / `busy-first` / `slow` / `garbage` を設定すると、失敗時の動作を確認できます。
- `node scripts/snapshot.mjs <GeniusのURL> [--mobile]` で、実際のページを `dev/real/` に保存します。Genius のスクリプトを除き、開発版と疑似モデルを組み込んだものです。
- 実際のモデルで訳を確認するときは、`.env.local` に `GEMINI_API_KEY=...` を書き、`npm run live -- <GeniusのURL> [--model …]` を実行します。訳と注の一覧が `tmp/report-*.md` に出力されます（無料枠を1回使います）。

```
src/
  core/      曲の行の整理（繰り返し、声だけの行）、プロンプト、応答の読み取り
  llm/       Gemini と Claude の呼び出し、モデルの選択と切り替え、エラーの分類
  platform/  GM_xmlhttpRequest とストレージ
  genius/    歌詞の読み取りと表示位置、Genius の注釈
  store/     設定、曲ごとの保存、タブ間のロック
  ui/        画面の状態（state.ts）、見出し行、訳の行、注、設定シート
  app.ts     全体の接続
```

設計の詳細は [docs/DESIGN.md](docs/DESIGN.md) にあります。
